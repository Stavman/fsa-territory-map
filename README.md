# FSA Territory Map

Interactive territory-planning map for Canadian Forward Sortation Areas (FSAs), initially focused on Montréal's South Shore and surrounding Québec.

## Features

- Search and select 3-character FSAs
- Create multiple named, color-coded territory layers
- Assign one FSA to multiple layers
- Show overlapping layer memberships with stacked outlines
- Add notes to each FSA
- Show/hide individual layers
- Save work automatically in browser local storage
- Export territory configuration as JSON

## Data

FSA polygons are loaded from Statistics Canada's 2021 Census Forward Sortation Area cartographic boundary service. Census FSAs may differ from current Canada Post operational delivery boundaries.
